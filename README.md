# 20 Games challenge in Odin and Raylib

Based on: [20 Games Challenge](https://20_games_challenge.gitlab.io/)

The idea is to recreate and build some games to build skills and confidence when
it comes to games programming.
These games should be smaller, at least to start with, better to build a few
smaller games, or vertical slices of larger games to build skills and then move
onto larger projects.

I want to start using just programming and code-libraries to build some of these
smaller games to really understand the fundamentals before I move onto making
games with Godot, Unity or similar applications.
